# הדשבורדים שלי

דף אינדקס אחד שמרכז את כל הדשבורדים: דשבורדים חיים שפורסמו ב-Vercel ודפים שנבנו ב-Claude.

## מה יש בדף

- **דשבורדים ב-Vercel:** חיובי עליות שבת, התחייבויות שבת, תורמי הדינר ושכירות תאים. הכניסה אליהם בהתחברות עם Google.
- **דפים ב-Claude:** תרומות אחרי הקמפיין, לוח יורצייט וימי הולדת, שכירות תאים וחובות עליות שבת.
- חיפוש לפי שם, תצוגה כהה כברירת מחדל והתאמה לנייד.

## מבנה הריפו

- `index.html` - הדף כולו בקובץ אחד, ללא תלות בספריות. הפונט היחיד נטען מ-Google Fonts.

## הוספה או הסרה של דשבורד

הרשימות נמצאות בתחילת קטע ה-`<script>` ב-`index.html`:

- `sites` - דשבורדים ב-Vercel. לכל אחד: `name`, `host` ו-`hint`.
- `pages` - דפים ב-Claude. לכל אחד: `name`, `url` ו-`date`.

מוסיפים או מוחקים שורה ברשימה המתאימה, ושומרים.

## הצגה מקומית

פותחים את `index.html` בדפדפן.

## פרסום כאתר

אפשר לחבר את הריפו ל-Vercel או להפעיל GitHub Pages מהענף `main`. אין שלב בנייה.
